# 시연 시나리오

포트폴리오용 GIF/영상을 찍을 때의 순서다. 백엔드와 웹 대시보드를 먼저 띄워두고,
앱은 에뮬레이터로 실행한다. 화면 두 개(앱 + 웹 대시보드)를 나란히 두면 연동이 잘 드러난다.

## 준비

1. `cd stockscan-api && ./gradlew bootRun` — 샘플 품목 4개가 들어간 상태로 시작.
2. `cd stockscan-web && python -m http.server 5500` 후 브라우저로 `http://localhost:5500`.
3. Android Studio에서 앱 실행.

## 촬영 순서

1. **웹 대시보드 첫 화면** — 샘플 품목 4개와 이력을 보여준다.
2. **앱 실행 → 목록** — 앱에도 같은 품목이 뜨는 걸 보여준다(같은 API).
3. **기존 품목 입고** — 스캔 버튼 → `생수 500ml` 바코드 스캔 → 상세 화면에서 입고 +12.
4. **웹 새로고침** — 생수 수량이 늘고 이력에 입고 한 줄이 추가된 걸 확인.
5. **신규 품목 등록** — 목록에 없는 바코드를 스캔 → 등록 화면 → 품목명·초기 수량 입력 → 등록.
6. **출고 처리** — 방금 등록한 품목을 출고 -N.
7. **웹 새로고침** — 신규 품목과 입고/출고 이력이 그대로 반영된 걸 마지막으로 보여준다.

3~4번(입고 → 웹 반영)과 5~7번(신규 등록 → 출고 → 웹 반영)이 핵심 장면이다.
"앱에서 스캔한 게 서버를 거쳐 웹에 그대로 나온다"가 한눈에 보이면 된다.

## 실기기로 찍을 경우

에뮬레이터 카메라로는 실제 바코드 스캔이 어색하니, 물리적 바코드(택배 상자, 음료수 등)를
쓰려면 실기기가 낫다. 이때 `app/build.gradle.kts`의 `API_BASE_URL`을 PC의 LAN IP로 바꾸고
(예: `http://192.168.0.10:8080/`) PC와 폰을 같은 네트워크에 둔다.
